## 1. Mapeo Transversal de Bloques y Clases
- **Bloques I–III (Diaps. 1–28 / Clase 01):** Crisis del éter, electromagnetismo de Maxwell, experimento de Michelson-Morley ($\Delta N \approx 0.4$ teórico vs $\Delta N < 0.01$ nulo) y dos postulados de Einstein (1905).
- **Bloque IV (Diaps. 29–34 / Clase 02):** Metrología de eventos, diagramas de Minkowski, distancia como magnitud derivada ($d = c\Delta t/2$) y protocolo del radar de Bondi.
- **Bloque V (Diaps. 35–44 / Clase 03):** Factor de Bondi $k = \sqrt{\frac{1+\beta}{1-\beta}}$, efecto Doppler relativista longitudinal ($\nu_{\text{rec}} = \nu_{\text{em}}/k$), redshift $z = k-1$ y composición 1D de velocidades ($v_{AC} = \frac{v_{AB}+v_{BC}}{1+v_{AB}v_{BC}/c^2}$).
- **Bloques VI–VIII (Diaps. 45–67 / Clase 04):** Boosts de Lorentz, invarianza del intervalo $\Delta s^2 = c^2\Delta t^2 - |\Delta\vec{x}|^2$, dilatación temporal ($\Delta t = \gamma \Delta t_0$), contracción de longitud ($L = L_0/\gamma$), conos de luz y causalidad.
- **Bloques IX–X (Diaps. 68–77 / Clase 04):** Dinámica relativista ($\vec{p} = \gamma m\vec{v}$, $E = \gamma mc^2$, $E_0 = mc^2$, $E^2 = p^2c^2 + m^2c^4$), física nuclear (fisión $^{235}\text{U}$, fusión estelar) y cronología 1600–1930.

## 2. Fórmulas Maestras del Documento
1. **Radar de Bondi:** $t_P = \dfrac{t_E + t_R}{2}, \quad x_P = c\left(\dfrac{t_R - t_E}{2}\right)$
2. **Factor de Bondi:** $k = \sqrt{\dfrac{1 + v/c}{1 - v/c}}$
3. **Efecto Doppler:** $\nu_{\text{rec}} = \nu_{\text{em}}\sqrt{\dfrac{1 - v/c}{1 + v/c}}$ (alejamiento)
4. **Composición de Velocidades:** $v_{AC} = \dfrac{v_{AB} + v_{BC}}{1 + \dfrac{v_{AB} v_{BC}}{c^2}}$
5. **Transformaciones de Lorentz:** $x' = \gamma(x - vt), \quad t' = \gamma\left(t - \dfrac{v}{c^2}x\right), \quad \gamma = \dfrac{1}{\sqrt{1 - v^2/c^2}}$
6. **Intervalo Invariante:** $\Delta s^2 = c^2 \Delta t^2 - \Delta x^2 = \text{invariante}$
7. **Dilatación y Contracción:** $\Delta t = \gamma \Delta t_0, \quad L = \dfrac{L_0}{\gamma}$
8. **Relación Energía-Momentum:** $E^2 = (pc)^2 + (mc^2)^2, \quad E_0 = mc^2$
